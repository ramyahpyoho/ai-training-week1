Employee Salary Analysis – Week 1 Project

1. Project Problem

The objective of this project is to analyse employee salary data to understand salary distribution, compare salaries across departments and cities, and identify useful business insights.

2. Dataset Description

The dataset contains 8 employee records and 5 columns:

- Employee ID
- Name
- Department
- Salary
- City

Python libraries used: Pandas, NumPy and Matplotlib.

3. Three Key Insights

1. The average employee salary is ₹58,500, while the median salary is ₹56,000.
2. The Finance department has the highest average salary of ₹90,000, while Sales has the lowest average salary of ₹41,000.
3. Mumbai has the highest average salary of ₹69,000, while Chennai has the highest employee count with 4 employees.

4. Two Recommendations

1. The organisation can review department-wise salary differences to understand compensation distribution and ensure fair salary practices.
2. The organisation can collect more employee records and additional details to improve future salary analysis and decision-making.

5. Limitations

- The dataset contains only 8 employee records.
- Only two numeric columns are available: employee ID and salary.
- There is no date column to analyse salary trends over time.
- The budget figures used in the merge exercise are sample values, not actual company budgets.
- The findings may not represent the entire organisation.

Conclusion

The project demonstrates data cleaning, exploratory data analysis, data merging, pivot tables and visualisation using Python. The analysis provides a basic understanding of employee salary distribution across departments and cities.
